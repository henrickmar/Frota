# FrotaViva

Sistema de gestão de frota: veículos, abastecimentos, manutenções e dashboard.

Stack: TanStack Start (React) + Tailwind + Supabase (banco e login).

## Rodar local
```sh
cp .env.example .env   # preencha as chaves do Supabase
npm i
npm run dev
```

Banco, usuário e publicação: veja `SETUP.md`.
